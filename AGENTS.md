# Projeto de qualidade do ar

Leia README.md e docs/EXECUCAO.md antes de alterar. Atualize documentação e registro de mudanças na mesma entrega.

O processamento analítico ocorre no navegador. O conector ISEQ é opcional e só faz requisições por ações explícitas do usuário; credenciais e sessões ficam em memória e jamais entram em arquivos exportados ou Git.

Preserve arquivos e valores de origem, linhas rejeitadas, conflitos e versões. Escola e hospital permanecem casos distintos. Referências sem validação documental produzem descrição ou impedimento fundamentado, não conformidade.

O sistema visual deriva dos tokens aprovados do shell Nexo. Fonte Segoe UI Variable/Segoe UI/Arial, temas claro/escuro e cores de séries separadas de estados. Alterações de escopo visual exigem conferir as decisões aprovadas, sem repetir confirmações já dadas.

Execute npm test e npm run build para alterações analíticas. Verifique a interface afetada em navegador. Não publique dados reais nem segredos. Publicação deve seguir a autorização atual e manter o beta preservado.
